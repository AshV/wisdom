## 🛠️ Step-by-Step Guide for Adding a New 100-Quote Batch

When adding a new batch of 100 quotes for an author:

### 1. Select the Next Sequential Range
- Check the highest current ID in `src/data/quotes/` (e.g. `q1000.json`).
- Assign next range (e.g. `q1001.json` to `q1100.json`).

### 2. Verify Primary Sources
- Sift quotes strictly from verified translations and primary texts.
- Discard apocryphal / misattributed quotes.
- Avoid duplicating any quotes already present in `src/data/quotes/`.

### 3. Ensure Schema Compliance
Each quote file (`qXXXX.json`) must strictly match:
```json
{
  "id": "q1001",
  "content": "Make the best use of what is in your power, and take the rest as it happens.",
  "author": "Epictetus",
  "authorSlug": "epictetus",
  "category": "Wisdom",
  "categorySlug": "wisdom",
  "mood": "reflective",
  "tags": ["control", "acceptance", "stoicism", "resilience"],
  "theme": "dark",
  "duration": 8
}
```

Allowed `mood` values:
- `reflective`, `motivational`, `serene`, `bold`, `melancholic`, `joyful`, `philosophical`, `romantic`

### 4. Build & Verify
Run the static site build to validate all schemas:
```bash
npm run build
```
Verify that all routes compile with **0 errors**.

### 5. Update Documentation & Roadmap
Mark the author as completed in this `TODO.md` file and update `walkthrough.md`.
