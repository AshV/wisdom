Getting Started with wiz-theme

Everything you need to integrate wiz-theme into your Astro project in under 3 minutes.

1. Installation

Install wiz-theme and Tailwind CSS v4 in your Astro project: 

npm install wiz-theme
npm install -D tailwindcss @tailwindcss/vite

2. Add Integration to astro.config.mjs

Register the theme integration in your Astro configuration: 

import { defineConfig } from 'astro/config';
import tailwindcss from '@tailwindcss/vite';
import { wizTheme } from 'wiz-theme';

export default defineConfig({
  vite: {
    plugins: [tailwindcss()],
  },
  integrations: [
    wizTheme({
      siteName: 'तत्व',
      subtitle: 'जीवन का सार',
      language: 'hi',
    }),
  ],
});

3. Render ReelFeed in your Page

Import BaseLayout and ReelFeed in src/pages/index.astro: 

---
import { BaseLayout, ReelFeed } from 'wiz-theme';

const quotes = [
  {
    id: "q-01",
    content: "The wound is the place where the light enters you.",
    author: "Rumi",
    authorSlug: "rumi",
    category: "Wisdom",
    categorySlug: "wisdom",
    mood: "reflective",
    tags: ["healing", "light"]
  }
];
---

4. Built-In CLI Commands

Manage content or generate batch vertical video reels directly from terminal: 

# Launch Local Admin Dashboard (Port 4242)
npx wiz-theme admin

# Automated batch export of animated 9:16 social videos (1080×1920)
npx wiz-theme generate --all
