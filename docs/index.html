API Reference

Configuration Options

All settings available in wizTheme({...}) in astro.config.mjs or as props to <BaseLayout>.

Property Type Default Description
siteName / siteTitle string 'Wisdom' Brand or site name. Appears in <title>, OpenGraph tags, top bar, and schema.
subtitle / tagline string '' Secondary site motto. Concatenated automatically into page titles.
language / lang 'en' | 'hi' | 'es' 'en' Primary language tag. Automatically selects locale dictionary and typography presets.
brandingText string siteName Watermark branding text rendered at the bottom of 9:16 keepsake card downloads.
consumerId / siteId string derived slug Firebase Realtime Database namespace isolating view, like, and share telemetry.
quotes QuoteData[] required Array of quote objects rendered into the vertical scroll-snap reel feed.
feedTitle string inherits siteName Title displayed in the fixed navigation overlay of the reel feed.
typography Partial<TypographyConfig> Language preset Font family overrides and Google Fonts stylesheet URL.
translations DeepPartial<Translations> Locale dictionary Custom string and label overrides for any component or modal dialog.
