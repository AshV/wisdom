Developer Setup

Quickstart Guide

Install and run the Wisdom theme in your Astro project in three straightforward steps.

1

Install the Package

Add wiz-theme and Tailwind CSS v4 to your Astro project:

Terminal 
npm install wiz-theme
npm install -D tailwindcss @tailwindcss/vite
2

Configure astro.config.mjs

Register the integration in your Astro configuration:

astro.config.mjs 
import { defineConfig } from 'astro/config';
import tailwindcss from '@tailwindcss/vite';
import { wizTheme } from 'wiz-theme';

export default defineConfig({
  vite: {
    plugins: [tailwindcss()],
  },
  integrations: [
    wizTheme({
      siteName: 'Wisdom',
      subtitle: 'Timeless Quotes, Reimagined',
      language: 'en', // Use 'hi' for dedicated Hindi sites
    }),
  ],
});
3

Render ReelFeed in your Page

Import BaseLayout and ReelFeed in src/pages/index.astro:

src/pages/index.astro 
---
import { BaseLayout, ReelFeed } from 'wiz-theme';

const quotes = [
  {
    id: "q-01",
    content: "The wound is the place where the light enters you.",
    author: "Rumi",
    authorSlug: "rumi",
    category: "Wisdom",
    categorySlug: "wisdom",
    mood: "reflective",
    tags: ["healing", "light"]
  }
];
---
4

Built-In CLI Commands

Manage quotes via the local admin dashboard or batch export 9:16 videos:

Terminal 
# Launch local browser admin dashboard
npx wiz-theme admin

# Automated batch export of animated 9:16 social videos
npx wiz-theme generate --all
API Reference

Configuration Options

All settings available to wizTheme({...}) in astro.config.mjs or as props to <BaseLayout>.

Property Type Default Description
siteName / siteTitle string 'Wisdom' / 'तत्व' Brand or site name. Appears in <title>, OpenGraph tags, top bar, and schema.
subtitle / tagline string '' Secondary site subtitle or motto. Automatically concatenated into title.
brandingText string falls back to siteName Watermark branding text printed at the bottom of generated 9:16 quote card images.
lang / language 'en' | 'hi' | string 'en' Primary BCP-47 language tag. Automatically selects dictionary & typography presets.
consumerId / siteId string derived slug Namespace identifier in Firebase RTDB isolating engagement telemetry.
quotes QuoteData[] required Array of quote objects rendered in the vertical scroll-snap reel feed.
feedTitle string inherits siteName Title displayed in the fixed navigation overlay of the reel feed.
typography Partial<TypographyConfig> Language preset Font family overrides and Google Fonts stylesheet URL.
translations DeepPartial<Translations> Language dictionary Custom string and label overrides for any component or modal.
